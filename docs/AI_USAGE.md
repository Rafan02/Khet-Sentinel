# AI usage log — Khet Sentinel

Robofest Buildathon requires AI assistance to be documented. This file is that
record.

## Tool

Grok Build (xAI), 9 September 2026, used to generate the working prototype,
field-grid simulation, documentation and pitch structure.

## What AI generated

- React / TanStack UI for the field grid, sensors, advise and guide pages
- Simulation engine (`src/lib/farm/engine.ts`) with transparent scoring
- Architecture, feasibility and README copy
- Visual language (rice-paper + paddy green, SVG plot textures)

## What AI did not do

- Invent a real trained neural net or claim field-measured accuracy
- Pull proprietary agritech source
- Hide prompts: this log plus the in-app Guide page are the disclosure

## Intent of the models on screen

Yield and blast numbers are **explainable scoring rules** standing in for a
later on-device model. They are labelled as nowcasts / scouts, not as certified
lab results. That is deliberate for Track C feasibility.

## Human ownership

Team reviews every plot rule, cost figure and pitch minute before submission.
Commit messages in the public repo are the audit trail.
